📖 API Guide

🚀 Quick Start

1. Get Your API Token

Purchase a plan and redeem your license key on our website to get your unique sk- token.

2. Integrate in 3 Lines of Code

We are fully compatible with the OpenAI API format. Simply change the base URL and API key:

# example.py
# Install the OpenAI SDK first: pip install openai

from openai import OpenAI

# Create a client pointing to our API endpoint
client = OpenAI(
    base_url="https://你的New-API域名",
    api_key="sk-你的令牌"
)

# Send a chat completion request
response = client.chat.completions.create(
    model="模型名称",
    messages=[{"role": "user", "content": "你好"}]
)

# Print the model's reply
print(response.choices[0].message.content)
